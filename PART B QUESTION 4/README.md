## IPO
Input: Price, quantity, tax and discount.
Process: subtotal = quantity x price, discounted amount = subtotal - (subtotal x discount) / 100, final bill = discounted amount + (discounted amount x tax) / 100
Output: Subtotal, discount, final bill.
